# 3. But be careful with crop inference

There is a major engineering trap here.

You cannot just run a crop and concatenate detections.

You need to convert crop coordinates back to the original frame:

```text
crop coordinates
      ↓
scale correction
      ↓
offset correction
      ↓
full-frame coordinates
```

Then perform duplicate suppression / association.

Example:

```text
Full detector:
P1 @ (600,740)

ROI detector:
P1 @ (598,742)

                    ↓
               same person
                    ↓
               merge detections
```

Otherwise you create duplicate boxes.

# 14. One more thing your new finding tells me

Your previous observation:

> "Nobody is small enough for tiling."

was based on **source-image intuition**.

Your new experiment demonstrates why that reasoning is dangerous.

You need to distinguish:

### Source pixel size

from

### Network pixel size

A person can be:

```text

```

but after preprocessing:


Those are completely different detector conditions.

So from now on, I'd make **effective network pixel height** a first-class diagnostic.

For every critical zone, report something like:

```text

Network height:      115 px
Inference scale:     1280
Critical-zone:       YES
```

Then you'll know exactly why a person disappears.
